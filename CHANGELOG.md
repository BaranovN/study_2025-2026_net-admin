# История изменений

Все существенные изменения проекта документируются в этом файле. Версии оформляются по правилам Semantic Versioning.

Формат основан на [Keep a Changelog](https://keepachangelog.com/ru/1.1.0/), а нумерация версий соответствует [Semantic Versioning](https://semver.org/lang/ru/).

## [Unreleased]

## [2.1.0] - 2026-10-06

### Добавлено

- Доклад «Простая и контекстная фильтрация пакетов» в формате QMD с иллюстрациями, библиографией и текстом выступления.
- Производные форматы доклада: PDF и DOCX для отчёта, PDF и автономный HTML для презентации.
- Локальные шрифты DejaVu и настройки сборки доклада через `make` на Windows.

## [2.0.0] - 2026-09-14

### Добавлено

- Содержательные отчёты и презентации для лабораторных работ 1–16 в формате QMD.
- Исходные задания, иллюстрации и ресурсы шаблона Quarto для каждой работы.
- Сборка отчётов в PDF и DOCX, презентаций в PDF и HTML.
- Единое соглашение об именовании файлов по схеме `net-admin-labNN-{report|presentation}`.
- Репозитории и релизы на GitHub, GitVerse и SourceCraft.

### Исправлено

- Метаданные курса, автора и репозитория.
- Правила Git для хранения всех производных форматов Quarto.
- Стабильная сборка PDF в Windows через XeLaTeX без автоматического обновления пакетов.

## [1.0.0] - 2026-09-08

### Добавлено

- Базовая структура репозитория курса на основе академического шаблона.
- Исходные задания, отчёты и презентации для лабораторных работ 1–16.
- Конфигурация Quarto и Makefile для локальной сборки материалов.
